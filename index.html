NIKIRO Platform

Meet NIKIRO — a smart, ROS 2–powered logistics System for modern industrial automation. It unifies autonomous navigation, intelligent vision, precision manipulation, and automated material handling under seamless mobile control.

⚡ Key Features

  • ✓ Autonomous Mobile Robot (AMR) built on ROS 2, utilizing SLAM for mapping and AMCL for localization
  • ✓ Cobot pick-and-place pipeline implemented using MoveIt Task Constructor (MTC) for task-level motion planning
  • ✓ End-to-end system control via a custom-developed native mobile application
  • ✓ Vision-based object detection and recognition using OpenCV
  • ✓ Sensor-integrated conveyor system with automated start/stop logic for material handling

🎯 Use Cases: Smart warehouse automation, seamless material transport, factory floor logistics, and autonomous inspections.
